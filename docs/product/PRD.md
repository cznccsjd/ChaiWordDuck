## 2. 产品概述

### 2.1 产品定位

**拆词鸭**是第一款专注于**成人英语长单词（8字母+）深度记忆**的学习产品，通过基于维特根斯坦"语言游戏"哲学的五步学习法，让长单词变得"有故事、可拆解、能记住"。

### 2.2 核心价值主张

| 传统方法 | 拆词鸭方法 |
|---------|-----------|
| 机械重复背诵 | 故事化深度理解 |
| 抽认卡 + SRS | 语言游戏 + 创意秘籍 + SRS |
| 工具书式词根列表 | 叙事化"组装故事" |
| 单一例句 | 双场景对照（思辨场 vs 生活场） |
| 事后纠错 | 预防式"犯规警告" |

### 2.3 目标用户

- **主要用户**: 考试备考群体（考研、托福/雅思/GRE）
- **次要用户**: 职场人士（英文文献阅读、商务沟通）
- **潜在用户**: 终身学习者（有基础，想突破长单词瓶颈）

### 2.4 产品愿景

成为成人学习者攻克长单词的首选工具，让"记不住的长单词"不再成为英语学习的拦路虎。

## 3. MVP 核心功能

### 3.1 游客模式 (Guest Mode) - P0

**设计理念**:
工具类产品应该"**先让用户爱上产品，再引导注册留存**"。核心功能（查词）应尽可能开放，限制应放在增值功能（收藏、历史、高级功能）上。

**功能规格**:
- 游客可查询 **10个单词/天**（从1次提升到10次）
- 可查看完整五步游戏手册（无功能阉割）
- **不能使用收藏功能**（核心转化点）
- **不能查看历史记录**（核心转化点）
- **不能使用AI辅助功能**（未来高级功能）

**设计依据**:
1. **竞品分析**：有道词典、欧路词典等工具类产品均提供免登录无限查词
2. **用户反馈**：用户期望"先体验功能，再决定是否注册"
3. **转化策略**：10次查询足够建立产品价值认知，通过收藏和历史功能引导注册
4. **技术实现**：基于IP+设备指纹识别，避免滥用

**引导注册时机**（渐进式引导）:

**阶段1：初次体验（查询1-3次）**
- 无干扰，让用户专注体验五步学习法
- 手册底部温和提示："注册后可收藏单词、查看学习历史"（小字提示，不打断）

**阶段2：产生粘性（查询4-7次）**
- 点击"收藏"按钮时，弹出注册引导："注册后可收藏单词，方便随时复习"
- 手册底部增加注册价值点："已查询X个单词，注册后可查看完整历史"

**阶段3：接近限制（查询8-10次）**
- 页面顶部显示："今日剩余查询次数：X/10"
- 搜索框下方显示："注册可获得每日50次查询 + 无限收藏"

**阶段4：达到限制（查询10次后）**
- 搜索框变为注册引导："今日免费查询已用完，注册可获得50次/天"
- 展示注册价值对比表（游客 vs 注册用户 vs 高级会员）
- 提供"明日再来"按钮（不强制注册）

**验收标准**:
- [ ] 首次访问无需登录，可直接搜索单词
- [ ] 游客每天可查询10个不同单词（重复查询不计次数）
- [ ] 游客点击收藏时弹出注册引导，文案："收藏功能需要注册，立即注册？"
- [ ] 游客查询1-3次时，手册底部显示小字提示（不打断）
- [ ] 游客查询8次后，页面顶部显示剩余次数（2/10）
- [ ] 游客查询10次后，搜索框变为注册引导界面
- [ ] 次日0点重置游客查询次数（基于IP+设备指纹识别）
- [ ] 已查询过的单词可无限次复习（不计次数，鼓励复习）

**技术要求**:
- **IP限流**：防止单一IP大量请求（30次/分钟）
- **设备指纹**：结合Cookie、localStorage、浏览器指纹识别（防止清除Cookie绕过）
- **优雅降级**：识别失败时降级为IP限流
- **防滥用机制**：异常行为（频繁查询、爬虫）自动限制

### 3.2 用户注册/登录 - P0

**功能规格**:

**注册方式**:
- 邮箱 + 密码注册
- 密码强度要求: 至少8位，包含字母+数字

**登录方式**:
- 邮箱 + 密码登录
- 记住登录状态（7天）

**密码找回**:
- 通过邮箱发送重置链接

**验收标准**:
- [ ] 邮箱格式验证（xxx@xxx.com）
- [ ] 密码强度实时提示（弱/中/强）
- [ ] 注册成功后自动登录并跳转首页
- [ ] 重复邮箱注册显示"该邮箱已注册，请直接登录"
- [ ] 登录失败显示"邮箱或密码错误"
- [ ] 登录失败5次后锁定账户10分钟
- [ ] 密码找回邮件5分钟内送达，链接24小时有效

**技术要求**:
- JWT Token 认证
- 密码 bcrypt 加密存储
- Rate Limiting 防暴力破解

### 3.3 单词查询与展示 - P0

**功能规格**:

**查询流程**:
1. 用户在首页搜索框输入单词
2. 系统判断词库中是否有预生成手册
   - 有: 立即返回（<2秒）
   - 无: AI生成手册（<10秒），显示"正在生成游戏手册..."加载动画
3. 展示完整五步手册

**五步内容结构**:

| 步骤 | 内容 | 字数要求 |
|------|------|---------|
| **核心游戏** | 一句话概括单词的"本质使用场景" | 15-30字 |
| **双场景对照** | 思辨场（正式/学术）+ 生活场（日常/口语）各1个例句 | 各30-50字 |
| **词根拆解** | 前缀+词根+后缀可视化拆解 + 50-100字词源故事 | 50-100字 |
| **犯规警告** | 最易犯的拼写/用法错误 + 记忆口诀 | 20-40字 |
| **通关秘籍** | 创意记忆技巧（视觉联想/谐音/故事） | 30-50字 |

**验收标准**:
- [ ] 搜索框支持回车键和点击按钮触发
- [ ] AI生成时显示加载动画，文案:"正在为你拆解单词..."
- [ ] 手册页面清晰展示五步内容（移动端响应式）
- [ ] 显示单词音标、词性、发音按钮（P1阶段实现）
- [ ] 单词不存在时提示"未找到该单词，请检查拼写"
- [ ] 手册底部显示"收藏"和"分享"按钮（P1阶段实现分享）
- [ ] 已查询过的单词从缓存返回（<1秒）

**技术要求**:
- 优先返回预生成的"黄金手册"（人工审核质量）
- AI生成使用GPT-4 API（初期）或GPT-3.5-turbo（成本优化）
- 生成结果存入数据库，避免重复生成

### 3.4 收藏功能 - P0

**功能规格**:
- 注册用户可收藏单词
- 免费用户收藏上限: **10个单词**
- 高级会员无限收藏

**功能细节**:
- 手册页面右上角显示"收藏"按钮（星星图标）
- 点击后星星变实心，Toast提示"已收藏"
- 再次点击取消收藏，Toast提示"已取消收藏"
- "我的收藏"页面展示所有收藏的单词卡片
- 支持搜索收藏的单词

**验收标准**:
- [ ] 游客点击收藏跳转注册页
- [ ] 注册用户点击收藏即时生效，无需刷新页面
- [ ] 免费用户收藏第11个单词时提示"收藏已达上限（10个），升级高级版可无限收藏"
- [ ] "我的收藏"页面按收藏时间倒序排列
- [ ] 收藏列表显示单词、音标、收藏时间
- [ ] 点击收藏列表中的单词可查看完整手册（不计入查询次数）

### 3.5 查询次数限制 - P0

**设计理念**:
采用"**自由体验 → 基础留存 → 深度付费**"的三层策略，核心功能开放，增值服务收费。

**功能规格**:

| 用户类型 | 查询次数 | 收藏限制 | 历史记录 | AI辅助功能 |
|---------|---------|---------|---------|----------|
| **游客** | 10次/天 | ❌ 不可收藏 | ❌ 无历史 | ❌ 无AI辅助 |
| **注册用户（免费）** | 50次/天 | ✅ 最多50个 | ✅ 完整历史 | ❌ 无AI辅助 |
| **高级会员** | ✅ 无限 | ✅ 无限 | ✅ 完整历史 | ✅ AI写作/口语 |

**限制规则**:
- 每天凌晨0点重置查询次数
- **已查询过的单词重新查看不计入次数**（鼓励复习，这是核心！）
- 从收藏列表进入不计入次数
- 从历史记录进入不计入次数

**转化逻辑设计**:

**游客 → 注册用户**（转化率目标：≥15%）
- **触发时机**：查询10次后、点击收藏时
- **核心价值点**：50次/天 + 收藏功能 + 历史记录
- **文案示例**："注册解锁每日50次查询 + 收藏单词 + 学习历史"

**注册用户 → 高级会员**（转化率目标：≥5%）
- **触发时机**：查询50次后、收藏50个后、使用AI功能时
- **核心价值点**：无限查询 + 无限收藏 + AI辅助（写作、口语）
- **文案示例**："升级Premium：无限查询 + AI写作批改 + 口语陪练"

**验收标准**:
- [ ] 游客页面顶部显示"今日剩余：X/10（游客模式）"
- [ ] 注册用户页面顶部显示"今日剩余：X/50"
- [ ] 高级会员页面顶部显示"高级会员：无限查询"
- [ ] 用完次数后搜索框下方显示相应引导文案
- [ ] 提供明显的"升级"按钮（游客→注册/注册→Premium）
- [ ] 已查询单词在搜索历史中标注"已学"，点击不消耗次数
- [ ] 复习单词时显示"复习模式：不消耗查询次数"提示

### 3.6 基础复习提醒 - P1

**功能规格**:
- 基于艾宾浩斯记忆曲线发送复习提醒
- 触发时间: 学习新单词后 **第1、3、7、15、30天**

**提醒方式（MVP阶段）**:
- 邮件提醒
- 默认发送时间: 每天晚上8点

**邮件内容示例**:
```
主题: 你有3个单词等待复习 | 拆词鸭

你好，鸭友！

你在3天前学习的单词现在是最佳复习时间：
1. accommodation - 住宿、调节
2. entrepreneurship - 创业精神
3. infrastructure - 基础设施

点击复习: [链接]

保持每天复习，长单词不再是难题！

拆词鸭
```

**用户设置**:
- 可在"设置"页面开启/关闭提醒
- 可选择提醒时间（早上8点/中午12点/晚上8点）

**验收标准**:
- [ ] 学习新单词后自动加入复习计划
- [ ] 邮件在指定时间准时发送（误差<5分钟）
- [ ] 邮件包含待复习单词列表（最多5个）
- [ ] 点击邮件链接直接跳转到单词手册（无需登录，Token验证）
- [ ] 用户可在设置中关闭提醒（默认开启）

## 5. 非功能性需求

### 5.1 性能要求

| 指标 | 要求 | 测量方法 |
|------|------|----------|
| **页面加载速度** | 首屏 < 2秒 | Lighthouse评分 ≥ 90 |
| **AI生成速度** | < 10秒返回结果 | 后台监控平均响应时间 |
| **API响应时间** | 95%请求 < 500ms | APM工具监控 |
| **并发支持** | 100-1000并发用户无卡顿 | 负载测试 |
| **数据库查询** | 单词查询 < 100ms | 慢查询日志监控 |

**优化策略**:
- CDN加速静态资源
- Redis缓存高频手册
- 数据库索引优化（单词、用户ID）

---

### 5.2 安全性要求

| 安全维度 | 要求 |
|---------|------|
| **数据传输** | 全站HTTPS（SSL证书） |
| **密码存储** | bcrypt加密 + 盐值 |
| **防暴力破解** | 登录失败5次锁定10分钟 + 验证码 |
| **API限流** | Rate Limiting: 30次/分钟/IP |
| **XSS防护** | 用户输入内容过滤与转义 |

## 9. 风险与缓解

### 9.1 产品风险

#### 风险1: AI生成内容质量不稳定

**风险等级**: 高
**影响**: 用户信任度下降，口碑受损

**缓解措施**:
- **预防**: 人工审核机制（初期100%审核），优化Prompt模板，预生成"黄金手册"
- **监控**: 用户反馈"内容错误"比例，AI生成内容评分
- **修复**: 用户举报后24小时内人工修正，定期更新Prompt

---

#### 风险2: 用户留存率低

**风险等级**: 高
**影响**: 产品无法持续增长，商业化困难

**缓解措施**:
- **产品策略**: 复习提醒（邮件/推送），学习打卡日历，成就系统
- **内容策略**: 确保记忆技巧有趣且有效，减少学习负担（每天3个单词）
- **运营策略**: 社群运营（学习打卡群），KOL合作（英语学习博主）

---

### 9.2 商业风险

#### 风险3: 获客成本高

**风险等级**: 中
**影响**: 用户增长缓慢

**缓解措施**:
- **内容营销**: 知乎高质量回答，小红书学习案例，B站教程视频
- **产品驱动增长**: 分享功能，邀请奖励机制（邀请好友各得1周会员）
- **合作推广**: 与英语学习社群/公众号/培训机构合作

---

#### 风险4: 游客转化率低

**风险等级**: 中
**影响**: 注册用户增长缓慢

**缓解措施**:
- **优化引导时机**: 查看完手册后3秒显示注册引导（非强制）
- **强化价值传递**: 明确告知注册后权益（3次/天、可收藏、查看历史）
- **降低注册门槛**: 邮箱+密码即可，未来考虑支持第三方登录（微信/GitHub）

---

### 9.3 技术风险

#### 风险5: 技术故障

**风险等级**: 中
**影响**: 用户体验受损，流失率上升

**缓解措施**:
- **监控告警**: 服务器监控（CPU/内存/磁盘），API监控（响应时间/错误率）
- **故障预案**: AI服务故障→降级到基础词典；数据库故障→Redis缓存应急
- **定期演练**: 每月一次故障演练，验证备份恢复流程

---

#### 风险6: 第三方依赖故障

**风险等级**: 中
**影响**: 核心功能不可用

**缓解措施**:
- **OpenAI API故障**: 准备国产模型备选（文心一言、通义千问）
- **邮件服务故障**: 准备备用邮件服务商（SendGrid + 阿里云邮件）
- **支付服务故障**: 微信支付 + 支付宝支付双通道

---

### 9.4 法律合规风险

#### 风险7: 内容版权问题

**风险等级**: 低
**影响**: 可能面临法律纠纷

**缓解措施**:
- 例句优先使用开源语料库（Tatoeba）或AI生成原创例句
- 避免直接复制商业词典内容
- 词源信息标注来源（如"根据Etymonline"）

---

#### 风险8: 用户隐私合规

**风险等级**: 低
**影响**: 违反《个人信息保护法》

**缓解措施**:
- 制定《隐私政策》和《用户协议》，用户注册时需勾选同意
- 仅收集必要数据（邮箱、学习记录、收藏数据），不收集敏感信息
- 提供用户数据导出/删除功能
- 数据加密存储和传输（HTTPS + 数据库加密）

## 13. 附录：竞品分析与设计对比（v1.1新增）

### 13.1 竞品分析

#### 有道词典
**策略**：完全免费查词，无登录限制
- **优点**：用户体验极佳，零门槛使用
- **商业模式**：广告变现 + 增值服务（会员、课程、翻译）
- **适用场景**：大众工具，海量用户

#### 欧路词典
**策略**：免费版无限查词，高级功能付费
- **优点**：核心功能开放，通过专业功能（词库、笔记、云同步）吸引付费
- **商业模式**：桌面版付费（98元）+ 移动版内购
- **适用场景**：专业用户，深度学习

### 13.2 拆词鸭的差异化策略

| 维度 | 有道词典 | 欧路词典 | 拆词鸭（v1.1） |
|-----|---------|---------|--------------|
| **核心功能** | 完全免费 | 完全免费 | 游客10次/天，注册50次/天 |
| **增值服务** | 会员、广告 | 专业词库、云同步 | 无限查询、AI辅助、无限收藏 |
| **目标用户** | 大众 | 专业学习者 | 长单词攻克者（考研/留学） |
| **差异化** | 综合工具 | 专业词典 | **五步游戏学习法** |

**拆词鸭的策略逻辑**：
1. **核心差异化**：我们的价值不是"查词"，而是"记住长单词"
2. **适度限制**：10次/天足够用户体验"五步学习法"的价值
3. **转化漏斗**：游客体验 → 注册收藏 → Premium深度学习
4. **避免竞争**：不与大众词典拼"免费无限"，而是拼"记忆效果"

### 13.3 v1.0 vs v1.1 设计对比

| 维度 | v1.0（旧设计） | v1.1（新设计） | 变更理由 |
|-----|--------------|--------------|---------|
| **游客查询次数** | 1次/天 | 10次/天 | 1次太少，无法建立产品价值认知 |
| **注册用户查询** | 3次/天 | 50次/天 | 3次对学习场景太少，用户体验差 |
| **引导时机** | 查询1次后立即引导 | 渐进式4阶段引导 | 避免打断用户，先体验后引导 |
| **技术识别** | IP + Cookie | IP + 设备指纹 | 防止清除Cookie绕过限制 |
| **转化目标** | 未明确 | 游客→注册15%，注册→Premium5% | 量化指标，便于优化 |
| **设计理念** | 限制体验 | 自由体验 | 工具类产品应开放核心功能 |

### 13.4 用户体验流程对比

**v1.0 流程（问题）**：
```
访问 → 查询1次 → 立即弹窗："注册才能继续" → 用户流失 ❌
```

**v1.1 流程（优化）**：
```
访问 → 自由查询10次 → 自然产生收藏需求 → 温和引导注册 → 转化成功 ✅
```

### 13.5 风险评估

#### 风险：游客次数增加，转化率可能降低？
**分析**：
- **反例**：有道词典完全免费，仍有大量付费会员
- **关键**：转化不靠"逼"，靠"价值"
- **策略**：收藏、历史、AI辅助才是真正的转化点

**缓解措施**：
1. 强化收藏和历史记录的价值（学习进度可视化）
2. 在查询5-7次时，展示"已学单词统计"（需登录查看）
3. Premium功能明确且有吸引力（AI写作批改、口语陪练）

#### 风险：滥用问题（爬虫、批量查询）
**缓解措施**：
1. IP限流：30次/分钟/IP
2. 设备指纹识别：防止切换浏览器绕过
3. 异常行为检测：频繁查询自动限制
4. Captcha验证：可疑行为触发人机验证
