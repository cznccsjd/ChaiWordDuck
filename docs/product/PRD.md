## 2. 产品概述

### 2.1 产品定位

**拆词鸭**是第一款专注于**成人英语长单词（8字母+）深度记忆**的学习产品，通过基于维特根斯坦"语言游戏"哲学的五步学习法，让长单词变得"有故事、可拆解、能记住"。

### 2.2 核心价值主张

| 传统方法 | 拆词鸭方法 |
|---------|-----------|
| 机械重复背诵 | 故事化深度理解 |
| 抽认卡 + SRS | 语言游戏 + 创意秘籍 + SRS |
| 工具书式词根列表 | 叙事化"组装故事" |
| 单一例句 | 双场景对照（思辨场 vs 生活场） |
| 事后纠错 | 预防式"犯规警告" |

### 2.3 目标用户

- **主要用户**: 考试备考群体（考研、托福/雅思/GRE）
- **次要用户**: 职场人士（英文文献阅读、商务沟通）
- **潜在用户**: 终身学习者（有基础，想突破长单词瓶颈）

### 2.4 产品愿景

成为成人学习者攻克长单词的首选工具，让"记不住的长单词"不再成为英语学习的拦路虎。

## 3. MVP 核心功能

### 3.1 游客模式 (Guest Mode) - P0

**功能说明**: 无需注册即可体验核心功能，降低用户尝试门槛。

**功能规格**:
- 游客可查询 **1个单词/天**
- 可查看完整五步游戏手册
- 不能使用收藏功能
- 无法查看历史记录

**引导注册时机**:
- 点击"收藏"按钮时
- 达到查询限制（1次/天）时
- 查看完整手册后3秒显示注册引导浮层

**验收标准**:
- [ ] 首次访问无需登录，可直接搜索单词
- [ ] 游客查询1次后显示"今日体验次数已用完，注册可获得3次/天"
- [ ] 游客点击收藏时跳转注册页，提示"注册后可收藏单词"
- [ ] 游客查看完手册3秒后显示引导："注册可收藏单词、查看历史"（可关闭）
- [ ] 次日0点重置游客查询次数（基于IP+Cookie识别）

---

### 3.2 用户注册/登录 - P0

**功能规格**:

**注册方式**:
- 邮箱 + 密码注册
- 密码强度要求: 至少8位，包含字母+数字

**登录方式**:
- 邮箱 + 密码登录
- 记住登录状态（7天）

**密码找回**:
- 通过邮箱发送重置链接

**验收标准**:
- [ ] 邮箱格式验证（xxx@xxx.com）
- [ ] 密码强度实时提示（弱/中/强）
- [ ] 注册成功后自动登录并跳转首页
- [ ] 重复邮箱注册显示"该邮箱已注册，请直接登录"
- [ ] 登录失败显示"邮箱或密码错误"
- [ ] 登录失败5次后锁定账户10分钟
- [ ] 密码找回邮件5分钟内送达，链接24小时有效

**技术要求**:
- JWT Token 认证
- 密码 bcrypt 加密存储
- Rate Limiting 防暴力破解

---

### 3.3 单词查询与展示 - P0

**功能规格**:

**查询流程**:
1. 用户在首页搜索框输入单词
2. 系统判断词库中是否有预生成手册
   - 有: 立即返回（<2秒）
   - 无: AI生成手册（<10秒），显示"正在生成游戏手册..."加载动画
3. 展示完整五步手册

**五步内容结构**:

| 步骤 | 内容 | 字数要求 |
|------|------|---------|
| **核心游戏** | 一句话概括单词的"本质使用场景" | 15-30字 |
| **双场景对照** | 思辨场（正式/学术）+ 生活场（日常/口语）各1个例句 | 各30-50字 |
| **词根拆解** | 前缀+词根+后缀可视化拆解 + 50-100字词源故事 | 50-100字 |
| **犯规警告** | 最易犯的拼写/用法错误 + 记忆口诀 | 20-40字 |
| **通关秘籍** | 创意记忆技巧（视觉联想/谐音/故事） | 30-50字 |

**验收标准**:
- [ ] 搜索框支持回车键和点击按钮触发
- [ ] AI生成时显示加载动画，文案:"正在为你拆解单词..."
- [ ] 手册页面清晰展示五步内容（移动端响应式）
- [ ] 显示单词音标、词性、发音按钮（P1阶段实现）
- [ ] 单词不存在时提示"未找到该单词，请检查拼写"
- [ ] 手册底部显示"收藏"和"分享"按钮（P1阶段实现分享）
- [ ] 已查询过的单词从缓存返回（<1秒）

**技术要求**:
- 优先返回预生成的"黄金手册"（人工审核质量）
- AI生成使用GPT-4 API（初期）或GPT-3.5-turbo（成本优化）
- 生成结果存入数据库，避免重复生成

---

### 3.4 收藏功能 - P0

**功能规格**:
- 注册用户可收藏单词
- 免费用户收藏上限: **10个单词**
- 高级会员无限收藏

**功能细节**:
- 手册页面右上角显示"收藏"按钮（星星图标）
- 点击后星星变实心，Toast提示"已收藏"
- 再次点击取消收藏，Toast提示"已取消收藏"
- "我的收藏"页面展示所有收藏的单词卡片
- 支持搜索收藏的单词

**验收标准**:
- [ ] 游客点击收藏跳转注册页
- [ ] 注册用户点击收藏即时生效，无需刷新页面
- [ ] 免费用户收藏第11个单词时提示"收藏已达上限（10个），升级高级版可无限收藏"
- [ ] "我的收藏"页面按收藏时间倒序排列
- [ ] 收藏列表显示单词、音标、收藏时间
- [ ] 点击收藏列表中的单词可查看完整手册（不计入查询次数）

---

### 3.5 查询次数限制 - P0

**功能规格**:

| 用户类型 | 查询次数 | 复习限制 |
|---------|---------|---------|
| **游客** | 1次/天 | 无历史记录 |
| **注册用户（免费）** | 3次/天 | 已查询单词可无限复习 |
| **高级会员** | 无限 | 无限 |

**限制规则**:
- 每天凌晨0点重置次数
- 已查询过的单词重新查看不计入次数（鼓励复习）
- 从收藏列表进入不计入次数

**验收标准**:
- [ ] 页面顶部显示"今日剩余次数: X/3"（免费用户）
- [ ] 用完次数后搜索框下方显示"今日次数已用完，明天再来或升级高级版"
- [ ] 提供明显的"升级高级版"按钮（橙色，显眼）
- [ ] 游客用完1次后显示"注册可获得3次/天"引导
- [ ] 已查询单词在搜索历史中标注"已学"，点击不消耗次数

---

### 3.6 基础复习提醒 - P1

**功能规格**:
- 基于艾宾浩斯记忆曲线发送复习提醒
- 触发时间: 学习新单词后 **第1、3、7、15、30天**

**提醒方式（MVP阶段）**:
- 邮件提醒
- 默认发送时间: 每天晚上8点

**邮件内容示例**:
```
主题: 你有3个单词等待复习 | 拆词鸭

你好，鸭友！

你在3天前学习的单词现在是最佳复习时间：
1. accommodation - 住宿、调节
2. entrepreneurship - 创业精神
3. infrastructure - 基础设施

点击复习: [链接]

保持每天复习，长单词不再是难题！

拆词鸭
```

**用户设置**:
- 可在"设置"页面开启/关闭提醒
- 可选择提醒时间（早上8点/中午12点/晚上8点）

**验收标准**:
- [ ] 学习新单词后自动加入复习计划
- [ ] 邮件在指定时间准时发送（误差<5分钟）
- [ ] 邮件包含待复习单词列表（最多5个）
- [ ] 点击邮件链接直接跳转到单词手册（无需登录，Token验证）
- [ ] 用户可在设置中关闭提醒（默认开启）

## 5. 非功能性需求

### 5.1 性能要求

| 指标 | 要求 | 测量方法 |
|------|------|----------|
| **页面加载速度** | 首屏 < 2秒 | Lighthouse评分 ≥ 90 |
| **AI生成速度** | < 10秒返回结果 | 后台监控平均响应时间 |
| **API响应时间** | 95%请求 < 500ms | APM工具监控 |
| **并发支持** | 100-1000并发用户无卡顿 | 负载测试 |
| **数据库查询** | 单词查询 < 100ms | 慢查询日志监控 |

**优化策略**:
- CDN加速静态资源
- Redis缓存高频手册
- 数据库索引优化（单词、用户ID）

---

### 5.2 安全性要求

| 安全维度 | 要求 |
|---------|------|
| **数据传输** | 全站HTTPS（SSL证书） |
| **密码存储** | bcrypt加密 + 盐值 |
| **防暴力破解** | 登录失败5次锁定10分钟 + 验证码 |
| **API限流** | Rate Limiting: 30次/分钟/IP |
| **XSS防护** | 用户输入内容过滤与转义 |
| **CSRF防护** | CSRF Token验证 |
| **隐私合规** | 符合《个人信息保护法》，提供数据导出/删除功能 |

---

### 5.3 可用性要求

| 维度 | 要求 |
|------|------|
| **系统可用性** | 99.5%（每月宕机 < 3.6小时） |
| **数据备份** | 每天自动备份数据库 |
| **监控告警** | 服务异常5分钟内告警 |
| **响应式设计** | 支持移动端（手机/平板）和桌面端 |
| **浏览器兼容** | Chrome/Safari/Firefox/Edge（最新版+前2版本） |

---

### 5.4 扩展性要求

**用户增长预期**:
- 第1个月: 100-500用户
- 第3个月: 1000-5000用户
- 第6个月: 10000-50000用户

**架构设计**:
- 前后端分离架构（便于横向扩展）
- 数据库读写分离（应对高并发读）
- 使用消息队列处理AI生成任务（避免请求超时）

## 7. 开发计划

### 7.1 Phase 1: 验证阶段（2周）

**目标**: 验证"五步语言游戏学习法"对用户记忆长单词的有效性

**交付物**:
- 20个高质量"黄金手册"（人工撰写）
- 简单展示页面（静态网页或Notion）
- 测试报告（10-20名用户反馈 + 记忆效果数据）

**关键指标**:
- 记忆准确率（Day 7测试）≥ 70%
- 满意度评分 ≥ 4.0/5.0
- 学习完成率 ≥ 60%

---

### 7.2 Phase 2: MVP开发（3-4周）

#### Week 1: 基础架构与用户系统

**前端**:
- 项目初始化（React + Tailwind CSS）
- 首页、登录/注册页面UI
- 响应式布局框架

**后端**:
- 数据库设计（用户表、单词表、收藏表、查询记录表）
- 用户注册/登录API（JWT认证）
- 密码找回功能

**DevOps**:
- 开发环境搭建
- CI/CD流程配置

---

#### Week 2: AI集成与单词展示

**前端**:
- 搜索框组件
- 单词手册详情页（五步内容展示）
- 加载动画

**后端**:
- AI集成（GPT-4 API）
- Prompt模板设计与调试
- 单词查询API（优先返回预生成手册，否则AI生成）
- 查询结果缓存（Redis）

## 9. 风险与缓解

### 9.1 产品风险

#### 风险1: AI生成内容质量不稳定

**风险等级**: 高
**影响**: 用户信任度下降，口碑受损

**缓解措施**:
- **预防**: 人工审核机制（初期100%审核），优化Prompt模板，预生成"黄金手册"
- **监控**: 用户反馈"内容错误"比例，AI生成内容评分
- **修复**: 用户举报后24小时内人工修正，定期更新Prompt

---

#### 风险2: 用户留存率低

**风险等级**: 高
**影响**: 产品无法持续增长，商业化困难

**缓解措施**:
- **产品策略**: 复习提醒（邮件/推送），学习打卡日历，成就系统
- **内容策略**: 确保记忆技巧有趣且有效，减少学习负担（每天3个单词）
- **运营策略**: 社群运营（学习打卡群），KOL合作（英语学习博主）

---

### 9.2 商业风险

#### 风险3: 获客成本高

**风险等级**: 中
**影响**: 用户增长缓慢

**缓解措施**:
- **内容营销**: 知乎高质量回答，小红书学习案例，B站教程视频
- **产品驱动增长**: 分享功能，邀请奖励机制（邀请好友各得1周会员）
- **合作推广**: 与英语学习社群/公众号/培训机构合作

---

#### 风险4: 游客转化率低

**风险等级**: 中
**影响**: 注册用户增长缓慢

**缓解措施**:
- **优化引导时机**: 查看完手册后3秒显示注册引导（非强制）
- **强化价值传递**: 明确告知注册后权益（3次/天、可收藏、查看历史）
- **降低注册门槛**: 邮箱+密码即可，未来考虑支持第三方登录（微信/GitHub）

---

### 9.3 技术风险

#### 风险5: 技术故障

**风险等级**: 中
**影响**: 用户体验受损，流失率上升

**缓解措施**:
- **监控告警**: 服务器监控（CPU/内存/磁盘），API监控（响应时间/错误率）
- **故障预案**: AI服务故障→降级到基础词典；数据库故障→Redis缓存应急
- **定期演练**: 每月一次故障演练，验证备份恢复流程

---

#### 风险6: 第三方依赖故障

**风险等级**: 中
**影响**: 核心功能不可用

**缓解措施**:
- **OpenAI API故障**: 准备国产模型备选（文心一言、通义千问）
- **邮件服务故障**: 准备备用邮件服务商（SendGrid + 阿里云邮件）
- **支付服务故障**: 微信支付 + 支付宝支付双通道

---

### 9.4 法律合规风险

#### 风险7: 内容版权问题

**风险等级**: 低
**影响**: 可能面临法律纠纷

**缓解措施**:
- 例句优先使用开源语料库（Tatoeba）或AI生成原创例句
- 避免直接复制商业词典内容
- 词源信息标注来源（如"根据Etymonline"）

---

#### 风险8: 用户隐私合规

**风险等级**: 低
**影响**: 违反《个人信息保护法》

**缓解措施**:
- 制定《隐私政策》和《用户协议》，用户注册时需勾选同意
- 仅收集必要数据（邮箱、学习记录、收藏数据），不收集敏感信息
- 提供用户数据导出/删除功能
- 数据加密存储和传输（HTTPS + 数据库加密）
