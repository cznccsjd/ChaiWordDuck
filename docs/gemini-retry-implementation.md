# Gemini服务用户友好重试逻辑实现

## 概述

为Gemini AI服务实现了用户友好的重试逻辑，提升用户体验，确保大部分临时性问题都能静默重试成功。

## 实现策略

### 重试原则
- **用户体验优先**：静默重试大部分临时性错误
- **逻辑错误不重试**：参数验证失败、词汇不存在等明确错误不重试
- **AIParseError重试**：解析错误很可能是网络传输问题，应该重试

### 时间策略
- **总重试时间**：控制在8秒内
- **重试间隔**：1秒 → 2秒 → 3秒（指数退避）
- **最大重试次数**：4次（1次初始 + 3次重试）
- **随机抖动**：±25% 避免重试风暴

### 错误分类

#### 应该重试的错误
- `AIParseError`（解析错误）
- `APIError`（大部分API错误）
- 网络超时、连接错误
- 限流错误（Rate limit）
- 服务器内部错误

#### 不应该重试的错误
- `ValidationError`（参数验证失败）
- `WordNotFoundError`（词汇不存在）
- `QuotaExceeded`（配额用完）
- `Permission Denied`（权限错误）
